The contrast is the point: OpenRouter is an API marketplace (nearly all text-generation, so vLLM covers it), while Hugging Face reflects the whole research frontier (image/video/speech are first-class, so you need vLLM + Triton + a diffusion path + a speech path). Engine mappings are architecture-capability estimates, not per-checkpoint guarantees.
